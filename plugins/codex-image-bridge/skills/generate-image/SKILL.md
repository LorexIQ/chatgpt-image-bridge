# generate-image

В Claude Code нет своего генератора изображений. Этот скилл вызывает `codex` CLI, у которого есть встроенный инструмент генерации картинок `image_generation`. Codex авторизован через подписку ChatGPT пользователя, поэтому API-ключ OpenAI не нужен.

## Когда использовать

Вызывай обёртку, когда пользователю нужна сгенерированная картинка. Например:

- «Сгенерируй hero-картинку для…»
- «Сделай мокап / логотип / аватар / иллюстрацию…»
- «Покажи, как мог бы выглядеть X»
- «Перерисуй эту картинку в другом стиле» (с `--image`)
- Дизайн-скилл работает по схеме «сначала картинка, потом код» и просит изображение

**Не** вызывай для:

- диаграмм, графиков, схем, SVG и UI-разметки — их точнее сделать кодом (mermaid, SVG, HTML);
- мелких программных PNG (однотонные плейсхолдеры, пиксели) — хватит пары строк Python;
- попиксельной правки существующего файла.

## Как вызывать

Запускай через инструмент **Bash** (на Windows это Git Bash, не PowerShell):

```bash
bash ${CLAUDE_SKILL_DIR}/bin/codex-image "<промпт>" <абсолютный-путь-к-результату.png> [--size WxH] [--image <файл>]...
```

- **Промпт** — плотный и режиссёрский: композиция, свет, камера и объектив, настроение, стиль. Короткий промпт даёт шаблонный результат.
- **Путь к результату** — абсолютный. Для черновиков подойдёт временная папка, для ассетов, которые нужно сохранить, — папка в проекте, например `design/`. Папка должна существовать.
- **`--size WxH`** — необязателен, без него размер выбирает модель. Передавай, только если пользователь назвал размер или макет требует определённых пропорций. Формат `1536x1024`.
- **`--image <файл>`** (можно несколько раз) — исходная картинка для редактирования или референс по стилю и композиции. В промпте опиши, как её использовать («сохрани композицию, поменяй палитру на…»).
- Генерация обычно занимает несколько минут. Ставь таймаут Bash на **максимум, 600000 мс**, или запускай в фоне и дождись завершения. Если вызов прерван или упёрся в таймаут, обёртка сама останавливает codex и убирает временные файлы.

Результат:

- **код 0** — в stdout абсолютный путь к картинке (на Windows в виде `C:/...`, его можно открыть через `Read`);
- **код 1** — codex не справился или инструмент не сохранил картинку; в stderr хвост лога codex и путь к полному логу;
- **код 2** — ошибка аргументов;
- **код 127** — codex не установлен.

После успешного вызова открой PNG через `Read` и оцени результат, прежде чем писать код или отвечать.

## Как это устроено

Обёртка запускает:

```
codex exec <флаги облегчения> --skip-git-repo-check -s workspace-write -C <временная-папка> "<промпт>" [-i <картинка>]...
```

с явным требованием вызвать инструмент `image_generation`, а не рисовать PNG на Python.

**Облегчённый запуск.** Всё, что не нужно для картинки, выключается: плагины, MCP-серверы из конфига codex, все скиллы, apps, browser и computer use, мультиагентность, shell, web search, память, `AGENTS.md`, хуки и команда `notify`. Фичи выключаются, только если установленная версия codex их знает. Настройки песочницы берутся из конфига codex.

**Модель и effort.** Картинку рисует сам инструмент, модель codex только передаёт ему промпт, поэтому скрипт фиксирует дешёвую модель `gpt-5.6-sol` и effort `low`, чтобы не тратить лимиты. Переопределять их (`CODEX_IMAGE_MODEL`, `CODEX_IMAGE_EFFORT`) стоит, только если пользователь сам об этом попросил.

**Проверка источника.** Инструмент `image_generation` сохраняет результат в `$CODEX_HOME/generated_images/<session id>/`. Обёртка берёт session id из лога codex и копирует в нужное место только эту картинку. PNG, созданный любым другим способом, не принимается, и вызов завершается ошибкой. Codex не работает с итоговым путём, поэтому отказы песочницы и путаница путей Windows/POSIX исключены, а старый файл перезаписывается только когда новая картинка действительно есть.

## Что нужно пользователю

- Установленный `codex` CLI: `npm install -g @openai/codex` (на macOS также `brew install codex`).
- `codex login status` показывает «Logged in using ChatGPT» — нужна подписка ChatGPT.
- Включена фича `image_generation` — по умолчанию включена (`codex features list | grep image_generation`).
- bash: на macOS и Linux есть, на Windows — Git Bash (им пользуется Claude Code) или WSL.

Если обёртка пишет «codex CLI не найден», попроси пользователя установить codex и выполнить `codex login`.

## Стоимость

- **Оплаты OpenAI API нет.** Вызовы расходуют лимиты Codex в плане ChatGPT — те же, что и обычная работа в Codex.
- Лимиты ограничены, поэтому не трать их на пробные картинки без нужды.
